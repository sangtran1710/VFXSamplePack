# ForgePilot Test Structure

`/Game/ForgePilot_Test` is the sandbox area for AI-generated or AI-edited working assets.

Rules:
- Keep temporary work inside `ForgePilot_Test` until visual approval.
- Do not place approved production assets here permanently.
- After approval, move the final asset into its destination project folder with proper Unreal asset moves.
- Do not dump mixed asset types into one folder.

Recommended folder usage:
- `/Game/ForgePilot_Test/_Inbox`
  - First-pass generated assets that have not been reviewed yet.
- `/Game/ForgePilot_Test/_Review`
  - Assets currently under visual or technical review.
- `/Game/ForgePilot_Test/_ApprovedToMove`
  - Assets approved and ready to be moved into production folders.
- `/Game/ForgePilot_Test/Materials/AutoGenerated`
  - New master materials, material functions, and utility materials created by the agent.
- `/Game/ForgePilot_Test/Materials/ProbeInstances`
  - Temporary MICs and lookdev probe instances.
- `/Game/ForgePilot_Test/Niagara/AutoGenerated`
  - New or duplicated Niagara systems and emitters under active iteration.
- `/Game/ForgePilot_Test/Niagara/PreviewSystems`
  - Preview-only or throwaway Niagara setups used to validate motion/readability.
- `/Game/ForgePilot_Test/Blueprints/Harnesses`
  - Test harness Blueprints, debug wrappers, and non-production control BPs.
- `/Game/ForgePilot_Test/Blueprints/RuntimeTests`
  - Runtime test Blueprints used to validate VFX triggers or sequencing.
- `/Game/ForgePilot_Test/Textures/ImportedSources`
  - Imported texture sources used only for iteration or evaluation.
- `/Game/ForgePilot_Test/Textures/DerivedMasks`
  - Masks, packed maps, or derived utility textures created during iteration.
- `/Game/ForgePilot_Test/Probes/Captures`
  - Probe helpers or capture-related assets used for validation workflows.
- `/Game/ForgePilot_Test/Probes/ReferenceFrames`
  - Reference-image helper assets or staging assets for visual comparisons.
- `/Game/ForgePilot_Test/Reviews`
  - Task-level phased review bundles.
  - The same agent may write Builder, Art, and QA outputs across different phases.
  - Recommended subfolders:
    - `<TaskName>/<PassName>/Builder`
    - `<TaskName>/<PassName>/Art`
    - `<TaskName>/<PassName>/QA`
    - `<TaskName>/<PassName>/Shared`
- `/Game/ForgePilot_Test/Recipes`
  - Asset-side helpers tied to recipe-driven experiments.
- `/Game/ForgePilot_Test/Scratch`
  - Disposable experiments that may be deleted at any time.
- `/Game/ForgePilot_Test/Legacy`
  - Older sandbox work that should not be used as the default destination for new assets.
