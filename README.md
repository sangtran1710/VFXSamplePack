# VFXSamplePack

Unreal Engine sample project with the ForgePilot editor automation plugin.

## Active ForgePilot Target

ForgePilot development is focused on Unreal Engine 5.7.

- Canonical plugin workspace: `Plugins/ForgePilot/Versions/UE5.7/Plugins/ForgePilot`
- UE5.3 is kept only as legacy compatibility/reference material.
